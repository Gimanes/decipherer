# decipherer

a python script to decipher messages using a simple substitution cipher.

# supported ciphers:

decipherer supports the following ciphers:
* substitution cipher (my cipher i guess)
* caesars cipher (W.I.P.)
* binary
* morse code

# status:

decipherer is in the state of being always developed until i got every cipher on here.

# usage:

usage is simple but first you need to install the required dependencies:
```
pip install -r requirements.txt
```
or:
```
pip install imageio
pip install numpy
```
then you can run the script
