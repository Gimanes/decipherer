# decipherer

a python script to decipher messages using a simple substitution cipher.

# supported ciphers:

decipherer supports the following ciphers:
* substitution cipher (my cipher i guess)

# status:

decipherer is in development and not yet ready to use other ciphers, but the substitution cipher is fully implemented and ready to use.

# usage:

usage is simple but first you need to install the required dependencies:
```pip install -r requirements.txt
```
or:
```pip install imageio
pip install numpy
pip install imageio.v2
```
then you can run the script
